# Studio Desk - Setup Guide for New Users

## Welcome! 👋

This guide will help you set up Studio Desk in 5 minutes and start managing your makeup business.

---

## **PART 1: Initial Setup (2 minutes)**

### Step 1: Create Your Account
1. Go to app.studiodesk.in
2. Click "Sign Up"
3. Enter your email and create a password
4. Verify your email

### Step 2: Create Your Studio
1. Enter your studio name (e.g., "Priya's Makeup Studio")
2. Add your phone number (optional)
3. Click "Create Studio"

**Done!** Your studio is ready. Now let's set up the features.

---

## **PART 2: WhatsApp Integration (2 minutes)**

### Why set this up?
- Send quotations automatically
- Send payment reminders
- Send booking confirmations
- Zero manual work!

### Setup Steps:
1. Go to **Settings > WhatsApp Integration**
2. Click **"Setup WhatsApp"** button
3. Follow the 6-step wizard:
   - Create a WhatsApp Business Account (free at business.facebook.com)
   - Create a Meta App
   - Generate API keys
   - Verify your phone number
   - Copy credentials to Studio Desk
   - Test with a sample message

**That's it!** WhatsApp is now connected.

---

## **PART 3: Payment Collection (1 minute)**

### Why set this up?
- Accept online payments from clients
- Get money in your account in 2 hours
- Auto-update booking status when paid

### Setup Steps:
1. Go to **Settings > Razorpay Integration**
2. Create a Razorpay account (razorpay.com)
3. Get your API credentials
4. Paste them in Studio Desk
5. Click "Save"

**That's it!** Online payments are now active.

---

## **PART 4: Start Using Studio Desk**

### Create Your First Lead
1. Go to **Enquiries** tab
2. Click **"New Lead"**
3. Enter client details
4. Click "Save"

### Send a Quotation
1. Go to **Quotations** tab
2. Fill quotation form
3. Check "Send via WhatsApp"
4. Click "Generate"
→ **Automatic:** Quotation sent to client's WhatsApp! ✅

### Track Payment
1. Client pays via WhatsApp link
2. Payment appears in **Payments** tab
3. Booking status updates automatically
4. View on **Analytics** dashboard

## **KEY FEATURES**

### 📋 **Enquiries** (CRM)
- Track leads through 8 stages
- New → Contacted → Quotation → Advance → Confirmed → Done
- Filter by status
- Quick actions (call, message, convert)

### 💅 **Bookings**
- Full booking details

- Track payments (advance + balance)
- Send reminders automatically

### 💬 **WhatsApp Messages**
- Quotations
- Invoices
- Payment reminders
- Booking confirmations
- Review requests

### 💳 **Payments**

- Manual entry

- Due amount alerts

### 📊 **Analytics**
- Revenue this month

### 👥 **Team**

- View performance

## **COMMON WORKFLOWS**

### Workflow 1: From WhatsApp Enquiry to Payment
1. Client sends WhatsApp: "Hi, interested in bridal makeup"
2. You save in Enquiries → Status: **New**
3. You call client for details
4. Update status to **Contacted**
5. Send quotation via WhatsApp → Status: **Quotation Sent**
6. Client pays 30% advance → Status: **Advance Pending** (auto-updated)
7. Booking confirmed → Status: **Confirmed**
8. Event happens → Status: **Done**
9. Auto-reminder sent asking for review

### Workflow 2: Team Assignment
1. Create booking
2. Click "Assign to Team" dropdown
3. Select team member (e.g., Priya)
4. Booking assigned → Priya gets all details
5. Track Priya's performance in Team dashboard

### Workflow 3: Multiple Events (Wedding Package)
1. Create 4 bookings (Haldi, Sangeet, Wedding, Reception)
2. Each booking: separate quotation, payment, reminder
3. View all 4 in calendar view
4. Track combined revenue
